## Statistical conventions

- **Error bars and CIs:** unadjusted paired 95% *t* CIs over 100 seeds.
- **Recall CIs in Fig. 3:** sequence-cluster bootstrap 95% CIs over 20 sequences.
- **Filled marker or † (Fig. 2, Table 1):** Holm-rejected within the registered family.
  - Family N: N1–N3.
  - Ablation family: A1, A2, A4, A4b.
  - Grid family: 12 contrasts.
  - RL family: 6 contrasts.
- **Hollow marker:** not rejected.
- **Fig. 3 inclusion rule, fixed before plotting:** all seven Holm-family contrasts of the UAVDT ablation block (A1, A2,
  A4, A4b, N1, N2, N3), both arms. X1 has no recall and is excluded.
- **Table 1 sources:**
  - reference row: ablation block (N2, N3; seeds 32100–32199);
  - settings: grid block (G1, G2; seeds 32200–32299);
  - learned incumbents: RL block (R1, R2; seeds 32000–32099; three checkpoints averaged).

## Supplementary data

| File | Content |
|---|---|
| `ix_paper_numbers.json` | Exact values plotted and tabulated, with source block and contrast IDs |
| `ix_contrasts_all.csv` | Every contrast of all 8 blocks: return CI, p, Holm, and recall (seed / cluster) under three class mappings |
| `ix_levels_all.csv` | Per-arm levels: return, ok / drop / late / quality-violation rates, PSNR, energy, goodput, controller time (p99 and the share of slots over 50 ms) |
| `ix_mode_utilisation.csv` | All 14 modes per block / arm / checkpoint: selections, share, compliant, below floor, late or dropped |
| `ix_train_action_hist.csv` | Executed training actions of the 9 stage-A RL runs. Off-policy runs: random warm-up and policy phases |
